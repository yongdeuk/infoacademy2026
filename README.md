# block2python

**엔트리 블록 ↔ 파이썬 코드 비교·분석 학습 앱**
2026학년도 광주 중등 정보 교과 아카데미 연구 과제 산출물

> 배포 주소 · <https://infoacademy2026.vercel.app>

---

## 무엇을 해결하려는 앱인가

중학교 정보 교과가 1학년에 집중 배치되면서 2·3학년에 학습 공백이 생기고, 고등학교 1학년이
텍스트 코딩(파이썬)을 처음 만날 때 진입 장벽이 크게 느껴집니다.
이 앱은 학생이 **중학교에서 이미 조립해 본 엔트리 블록**을 출발점으로 삼아,
그 블록이 파이썬에서는 **어떤 명령어가 되고, 어떤 방식으로 동작하는지**를
나란히 놓고 확인하도록 만들었습니다.

## 학습 개념 6가지

| 개념 | 엔트리 카테고리 | 다루는 핵심 |
|---|---|---|
| 변수 | 자료 | `정하기` → `=`, `만큼 더하기` → `+=`, `묻고 대답 기다리기` → `input()` |
| 리스트 | 자료 | `항목 추가` → `append()`, **엔트리 1번째 = 파이썬 [0]** |
| 연산자 | 계산 · 판단 | `몫/나머지` → `//` `%`, `그리고/또는/아니다` → `and/or/not`, `=` vs `==` |
| 선택구조 | 흐름 · 판단 | ⊂자 블록 → 콜론과 4칸 들여쓰기, 중첩 `아니면` → `elif` |
| 반복구조 | 흐름 | `번 반복하기` → `for ~ range()`, **`될 때까지 반복` → `while` (조건이 뒤집힘)** |
| 함수 | 함수 | `함수 정의하기` → `def`, **엔트리에 없는 `return` 개념** |

## 다섯 가지 학습 모드

1. **블록 대응표** — 블록 하나하나가 어떤 파이썬 명령어가 되는지 확인하고, 아래 입력칸에 **직접 쳐 보기**
2. **나란히 비교** — 같은 프로그램을 두 언어로. 블록이나 코드 줄을 클릭하면 짝이 함께 표시
3. **한 단계씩 실행** — 블록과 코드를 동시에 짚어 가며 실행. 변수 상자·리스트 칸·조건 판정·반복 회차를 눈으로 확인
4. **따라 치기** — 블록을 보며 프로그램 한 편을 한 줄씩 타자 연습처럼 입력. 글자별 정오 표시, 정확도·분당 타수 기록
5. **직접 실습 · 채점** — 개념마다 2문제. 파이썬 코드를 직접 고쳐 쓰고 여러 입력값으로 자동 채점 (Ctrl+Enter 로 채점)

## 기술 메모

- **의존성 없는 단일 HTML 파일**입니다. 인터넷 없이 열어도 동작합니다(웹폰트만 온라인에서 받아옵니다).
- 파이썬 실행은 브라우저 안에서 도는 **자체 제작 미니 인터프리터**가 담당합니다.
  변수·리스트·연산자·if/elif/else·while·for·def/return·f-string·주요 내장 함수를 지원하며,
  오류 메시지를 **학생이 읽을 수 있는 우리말 안내**로 바꿔 보여 줍니다.
  (예: `NameError` → “‘score’ 라는 이름을 아직 만들지 않았어요.”)
- 자동 채점은 과제별 여러 입력값 세트를 실제로 실행해 출력을 비교합니다.
- 학습 진행 상황은 브라우저 `localStorage` 에 저장됩니다.
